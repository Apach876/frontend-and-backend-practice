Семестровая работа

Разработка веб-приложения для учета задач

Полноценное веб-приложение с использованием HTML, CSS, JavaScript и Bootstrap для управления задачами и проектами.

Основные функции:

  • Создание, редактирование и удаление задач
  • Категоризация задач по проектам
  • Установка приоритетов и сроков выполнения
  • Фильтрация и поиск задач
  • Экспорт данных в формате CSV

Используемые технологии:

HTML5 CSS3 JavaScript Bootstrap 5 LocalStorage
